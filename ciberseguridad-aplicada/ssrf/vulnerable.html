SSRF: cuando el servidor pide lo que tú le dices

En un ataque de Server-Side Request Forgery, el atacante hace que el servidor visite una URL por él. El servidor sí tiene acceso a la red interna; el atacante no. Escribe una URL o elige una de abajo y compara qué hace cada versión del código.
